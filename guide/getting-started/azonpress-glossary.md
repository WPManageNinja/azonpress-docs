# AzonPress Glossary

This glossary defines common terms used throughout the AzonPress documentation to help you understand key features and concepts.

## A

**Add-to-cart Button:** A specialized call-to-action button that allows visitors to add products directly to their Amazon shopping cart from your website.

**Amazon Product Advertising API Integration:** The core system that connects your WordPress website to Amazon’s API, enabling the plugin to fetch real-time product data.

**API Request Handler:** A backend component responsible for managing secure communication and data exchange between your server and Amazon’s services.

**Automatic Affiliate Link Generation:** A feature that automatically converts standard Amazon product URLs into affiliate links containing your unique tracking ID.

## B

**Buy Button Generator:** A user interface tool that creates customizable buttons, allowing visitors to purchase products on Amazon with a single click.

## C

**Classic Editor Compatibility:** Full support for the legacy WordPress Classic Editor, allowing users to insert products and tables without using the block editor.

**Comparison Tables:** Structured, high-conversion layouts that display multiple Amazon products side by side for easy comparison.

**cURL-based HTTP Communication:** A secure server-side method used by the plugin to request and retrieve data from Amazon’s external services.

**Custom Product Templates:** Predefined or user-defined layouts that control how Amazon products are displayed through templates or custom API endpoints.

## G

**Gutenberg Block Support:** Native integration with the WordPress block editor, providing dedicated blocks for inserting products and comparison layouts.

## I

**Image Size Optimization:** A performance feature that automatically resizes Amazon product images to improve site loading speed.

## M

**Mobile-specific Product Labels:** UI elements designed specifically for mobile users to improve readability and interaction on smaller screens.

## N

**No-follow Affiliate Links:** A link attribute (`rel="nofollow"`) applied to affiliate links to prevent search engines from passing SEO authority.

## P

**PHP Minimum Requirement:** The lowest supported PHP version (7.4) required for the plugin to function securely and efficiently.

**Price and Discount Formatting:** A feature that formats product prices and highlights discounts according to your site’s design settings.

**Product Table Builder:** A tool used to create responsive tables that organize Amazon product information into rows and columns.

## R

**Responsive Layouts:** Design structures that automatically adapt product tables and grids to different screen sizes, including mobile and tablets.

## T

**Table Duplication:** A productivity feature that allows users to clone existing product tables to save time when creating similar layouts.

## W

**WordPress Settings API Integration:** A standardized backend system used to securely store and manage plugin configuration settings in the database.
